# README visual assets

Drop the following files into this directory using these exact names:

| Filename | Use | Recommended source |
|---|---|---|
| `metropt-explorer-walkthrough.gif` | Main README walkthrough | Short 12–18 second recording of the explorer: overview → compare models → event transfer → July timeline |
| `study-overview.png` | First static snapshot | Screenshot showing the research question, study flow, dataset figures and main conclusion |
| `event-transfer.png` | Main result snapshot | Screenshot showing May, June and July AP-lift transfer at the 1-hour horizon |
| `model-comparison.png` | Optional supporting snapshot | Screenshot showing the model, horizon, seed and event controls with the comparison chart |

The README displays the GIF and the first two screenshots immediately. The model-comparison image is inside the collapsed snapshot section so it is available without making the landing page crowded.

The GIF is preferred over the original MP4 because GitHub README pages display it directly. Keep it short and readable; do not include browser tabs, personal files or unrelated desktop content.
